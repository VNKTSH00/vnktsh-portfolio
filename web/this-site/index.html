vnktsh.com, from scratch

No framework, no page builder, no template. Just files a browser can open, cooked the way I'd cook for friends: slowly, tasting as I go, and sending things back when they aren't right.

Ingredients

Short list, on purpose. Everything the page needs ships with the page.

On the plate

What your browser downloads.

  • HTML — one file per page
  • CSS — one stylesheet, driven by custom properties
  • JavaScript — one small script, no libraries
  • Fraunces & Inter — variable fonts, self-hosted

In the kitchen

Tools that never reach you.

  • Python — draws the background motifs
  • Headless Chrome — renders the link-preview cards
  • Bash + git — cuts, tags and restores releases

From the market

The two outside services.

  • Cloudflare — serves and caches the site
  • Web3Forms — delivers the contact form

Method

AI did much of the chopping. Each step says what was built and the decision that was mine to make.

  1. Write the argument before the page

    The site started as a paragraph, not a layout: software can be given away like a home-cooked meal. That paragraph sits on the home page word for word, and every design choice after it had to agree with it.

    My callNothing here should read like a pricing page.

  2. Put the whole look in one place

    Every colour, font, radius and shadow is a CSS custom property in a single :root block. Change a token and the whole site re-themes. The palette is contrast-checked against the paper background: body text and links clear 4.5 : 1, and the gradient headings clear 3 : 1 at the large sizes they're used at.

    My callWarm paper and terracotta, with a soft serif instead of a tech-looking sans.

  3. Draw the background in code

    The faint line art behind the pages is five motifs, generated by a Python script and embedded as SVG data URIs, so they cost no extra downloads. The important one is a pulli kolam, the looped pattern drawn in rice flour at the threshold of a Tamil home to welcome whoever arrives. They stay at 5 to 8 percent opacity so they never compete with the words.

    My callThe kolam goes behind every hero, because it's how a home says welcome.

  4. Taste it on a phone

    On an iPhone, a sideways swipe used to slide the page into blank space. The cause was a decorative shape with nothing clipping it, plus a Safari quirk where a sticky header defeats overflow-x: hidden on the body. Now every section clips its own decoration, and the page is checked to be exactly as wide as the screen. Animations switch off for anyone who has asked their device for reduced motion.

    My callIf it's awkward on my phone, it isn't finished.

  5. Make it quick to open

    The fonts used to come from Google Fonts, which meant two extra connections before the first word could render. They're now self-hosted variable fonts, trimmed to the Latin character sets, with the two most-used files preloaded. Photos are WebP, the About photos load lazily, and all of the site's behaviour fits in one small script.

    My callNo framework. A page this size doesn't need one.

  6. Make it easy to find and share

    Every page has a canonical URL, a sitemap entry and Open Graph tags. Structured data tells search engines who made the site and what MoneyBook is. The link-preview images are an HTML page rendered to 1200 × 630 by headless Chrome, then saved as JPEG so each stays under 100 KB.

  7. Take messages without a server

    The contact form posts to Web3Forms, which delivers each message to my inbox, so there's no server of mine to run. The page shows a friendly message whether the send works or fails, and a hidden honeypot field catches most spam bots.

  8. Keep every version

    A small shell script cuts each release: it tags it in git, logs a line in the version history, and writes a version.json so anyone can see what's live. Any old version can be restored as a new release, so nothing is ever lost. Because the CDN caches the stylesheet hard, its ?v= number goes up with every CSS change.

    My callEvery visible change gets a release, however small.
