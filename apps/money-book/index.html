Download now On Google Play — coming soon
  1. Tap Download now, then open the file when it finishes.

  3. Play Protect may offer to scan the app, or warn that the developer isn't recognised. Both are about the app being new to Google, not about anything found in it. Choose Install anyway or More details → Install.

Version 1.4.3 · 29 MB · macOS 12 or newer · Apple silicon & Intel

Download now On the Mac App Store — not planned yet
  1. Open the downloaded .dmg and drag Money Book into your Applications folder.
  2. The first launch will say the app can't be opened because Apple cannot check it. Apple's check costs $99 a year to run, and this app is free — so it isn't signed up for it.

  4. macOS asks once. After that it opens like any other app.

It can't reach the internet

MoneyBook doesn't request internet access at all. Android enforces that at the system level, so there is no version of this app that can quietly upload anything — not your transactions, not your receipts, not an analytics ping.

  • No accounts, no login, no server
  • No analytics, crash reporting or ad SDKs
  • Your ledger lives in the app's private storage
  • Camera is only for receipt photos, which stay put

You can verify the file

Every download's SHA-256 fingerprint is published above. If the number your computer calculates matches, the file is byte-for-byte the one I built — nothing was swapped or injected on the way to you.

Updates can only come from me

The Android build is signed with a release key only I hold. Android refuses any update signed by a different key, so a copy of MoneyBook picked up elsewhere can never replace the one you installed from here.

  • Properly release-signed, not a test build
  • Same key for every future version
  • Optional biometric lock on the app itself
